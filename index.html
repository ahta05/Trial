Panduan Penggunaan

1. Buka aplikasi TrekLog dan lakukan Login/Registrasi terlebih dahulu.

2. Lengkapi Identitas Mahasiswa di menu Setting.

3. Untuk mencatat kegiatan, tekan tombol + di halaman utama.

4. Isi form kegiatan, lampirkan bukti foto, lalu tekan "Upload ke Draft".

5. Cek kembali data di tab Draft. Jika sudah yakin benar, tekan "Konfirmasi".

6. Data yang sudah dikonfirmasi akan berpindah ke tab Logbook.

7. Setelah selesai PKL, buka Setting > Export Laporan PDF untuk mengunduh laporan lengkap.

FAQ

Apakah data saya aman?

Ya, data tersimpan aman di cloud dan hanya bisa diakses menggunakan akun Anda sendiri.

Saya salah input data yang sudah dikonfirmasi?

Data yang sudah dikonfirmasi tidak dapat diubah. Tambahkan data koreksi baru melalui form Input.

Apa fungsi Backup & Restore?

Backup mendownload semua data sebagai file JSON. Restore memulihkan data dari file backup tersebut.
